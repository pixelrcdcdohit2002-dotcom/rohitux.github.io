# Rohit Patel — UI/UX & Graphic Design Portfolio

## GitHub Pages
1. Create a GitHub repository named `YOUR-USERNAME.github.io`.
2. Upload `index.html` and `style.css`.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch → main → /(root)** and Save.
5. Your portfolio will be available at `https://YOUR-USERNAME.github.io`.

## Before publishing
- Replace `your@email.com` in `index.html` with your real email.
- Replace LinkedIn/Instagram `#` links with your profiles.
- Replace the sample project artwork with your actual project images/case studies.
