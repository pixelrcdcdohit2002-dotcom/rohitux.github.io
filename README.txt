# Rohit Patel — Premium Portfolio

## Upload to GitHub Pages

1. Extract this ZIP.
2. Open your GitHub repository:
   `rohitcreative.github.io`
3. Replace the old `index.html`, `style.css`, and `script.js` with these files.
4. Commit changes.
5. Open your GitHub Pages URL.

## Important edits

- Replace `YOUR PHOTO` in `index.html` with your portrait/photo.
- Replace the four project placeholder blocks with your actual project images.
- Replace the Behance URL if your profile URL changes.
- Update email/phone if needed.
- For individual projects, replace the Behance links with direct project links.

The design is responsive for desktop and mobile.
